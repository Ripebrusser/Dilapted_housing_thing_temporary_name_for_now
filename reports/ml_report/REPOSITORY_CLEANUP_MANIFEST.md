# Repository Cleanup Manifest

**Nothing listed here has been deleted or moved.** The brief asked for a manifest
rather than a cleanup, because every item below is either data that must remain
reproducible or an artefact whose removal would destroy evidence. Each entry
states what it is, why it exists, and the recommended action for whoever
packages the submission.

## 1. Duplicated dataset copies (≈49 MB, safe to omit from a submission archive)

| Path | Relationship |

| `datasets/downloads/` | Original archives as downloaded |
| `datasets/raw/` | Read-only copies actually read by the code |

Spot-hashed file pairs across these trees are byte-identical. The code reads
**only** `datasets/raw/`. Recommendation: keep `datasets/raw/`, exclude the three
`samrus (n)` directories and `datasets/downloads/` from a submission archive.
Do not delete them locally while the project is still being marked — they are the
only copy of the original delivered archives.
