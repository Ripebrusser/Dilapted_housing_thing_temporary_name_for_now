# Dataset Register

All datasets were **already present** in the workspace; nothing was downloaded.
Original archives and extracted folders were left untouched. Working copies were
placed under `datasets/raw/` and the archives under `datasets/downloads/`.

Machine-specific absolute paths are deliberately omitted; paths are relative to
the repository root.

## 3. Provenance

The files arrived as three owner-supplied archives (`samrus (1..3).zip`). Their
publisher-level provenance is **not independently verified** in this phase:

- D1 matches the widely circulated "India Census 2011" district dataset in shape
  (640 districts × 118 columns) and its population column sums exactly to India's
  2011 population (1,210,854,977), so the *population* fields are sound. One of
  its columns is nonetheless mislabelled — see `DATASET_AUDIT.md` §3.
- D2's structure matches the Census HHA table (house condition, materials,
  amenities, assets) but the delivered file carries shares, not counts, and has a
  damaged trailing column block.
- D4's figures reproduce Census 2011 slum aggregates at state level.

**Action for Phase 2 (owner decision required):** record a citation and source URL
for each of D1, D2, D4 so the final report can reference an authoritative table.

## 4. Licence / redistribution

Raw data are treated as third-party material: `datasets/raw/` and
`datasets/downloads/` are excluded from version control by `.gitignore`. Do not
publish raw rows; publish aggregates and code.

## 5. Register maintenance

`datasets/metadata/dataset_manifest.csv` is the machine-readable version of §1 and
is regenerated by `py src/data/audit_datasets.py`. Update this document by hand
whenever a dataset is added, replaced or retired.
